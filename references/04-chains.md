# 传导链 · 战略轴

> 传导链管"国际事件怎么走到中国"，战略轴管"同一议题的时间线怎么演进"。
> 链与轴都是**框架**，节点会过期，路径不会。节点示例取自 2026 年实跑记录，只用于说明范式。

## 一、9 条全球传导链

| 链 | 起点 | 传导路径 | 中国观察点 |
|---|---|---|---|
| **金融链** | 日元套利盘 / 美债收益率 | USD/JPY → 全球流动性 → 美股久期 → AI 资本开支 | 汇率、10Y/30Y、半导体指数、VIX、准备金/RRP |
| **通胀-选举-战争日程链** | 战场与航道 | 打击能源设施 → 油价 → 通胀预期 → 选举政治 → 战争时间表 → 释储平抑 | 油价三档、柴油裂解价差、释储进度、选举日 |
| **能源链** | 中东冲突 / 海峡通航 | 油价 → 成品油调价 → 进口成本 → 通胀 | 油价、海峡通行、战略储备 |
| **通道税与运保链** | 海峡通行与保险 | 通行中断/保费上升 → 运力与保险定价 → 布-WTI 价差 → 到岸成本与炼化毛利 | 价差箱体、VLCC 运价、战争险费率、通行量 |
| **供应链链** | 出口管制 / 供电瓶颈 | 半导体/稀土 → 全球价格 → 国产替代 | 存储部件进口、先进封装、算电协同、储能 |
| **气候链** | 厄尔尼诺/极端天气 | 干旱 → 水电/核电 → 能源 → 农业 | 雨带偏移、粮食安全、新能源出口 |
| **秩序重排链** | 美国收缩 / 吃盟友 | 盟友离心 → 外交窗口 → 贸易结构重排 | 与各区域的双边节奏、全球南方、一带一路 |
| **美元信用链** | 美元霸权租息 → 美债扩张 | 美债扩张 → 长端高位 → 货币工具失效 → 结算松动 → 主权资本转向 | 30Y、海湾防务多元化、结算货币、黄金、主权资本 |
| **制裁-反制链** | 制裁工具化 | 单边制裁 → 反制 → 盟友被迫选边 → 工具边际收益递减 → 反制联盟成型 | 对美反制、被制裁国对华转向、本币结算空间 |

**归属规则**：

- 单日国际条目至少归 1 条链；跨链事件必须双标注并写交叉影响（例：海峡冲突＝能源链＋通道税链＋通胀-选举链＋金融链＋美元信用链＋制裁-反制链）
- 每条链每月检查是否有**新起点**（新起点比新节点重要）
- 链上的价格观察位只作"阈值登记"，不构成交易建议

## 二、18 条战略轴

每条轴维护三样：**驱动变量、当前阶段、判据**。轴名稳定，阶段会迁移。

| # | 轴 | 驱动变量 | 判据（看什么算推进） |
|---|---|---|---|
| 1 | 换届时钟轴 | 党代会日程 | 达标期 → 延续期（政策真空）→ 定盘期，三段是否按日历走 |
| 2 | 治党-台账-巡视轴 | 组织纪律与考核 | 巡视对象变化、"一把手"约束条款、整改与用人是否锁在同一句 |
| 3 | 美伊/通道税轴 | 海峡与保险定价 | 价差箱体是否守住、谈判是否只吐战争溢价 |
| 4 | 俄乌冲突轴 | 战场点位与谈判切割 | 谈判与停火是否脱钩、换俘、打击频率 |
| 5 | 美国中期选举轴 | 硬日期（选举日） | 选举后第一个动作（真打/复谈/继续拖） |
| 6 | 日本-东北亚配对轴 | 对日定性与半岛互动 | 定性是否加码、规格是否降档、半岛是否升温 |
| 7 | 中东去美国化轴 | 会场与会籍 | 会议主办权迁移、共同防御条款是否落地兵力 |
| 8 | 欧洲轴 | 能源成本与政治撕裂 | 天然气价格、抗议扩散、对俄通道是否自建 |
| 9 | 中美关系轴 | 关税与规则 | 协议是否脱离"名词层"、部长级接触频次 |
| 10 | AI 秩序供给轴 | 国际组织与立法 | 协定批准、标准提案、产业落地（AI 原生工厂） |
| 11 | 电力-算力-六张网轴 | 电价机制与算力需求 | 市场化交易量、弃风弃光率、特高压投产、虚拟电厂容量 |
| 12 | 数据要素-资产化轴 | 确权与计价 | 产权登记量、数据交易所成交、入表案例、结算层归属 |
| 13 | 贴息-价格轴 | 财政杠杆与价格改革 | 贴息余额与不良率、公共事业价格调整节奏、LPR 与存款利率谁先动 |
| 14 | 财政-信用缺口轴 | 支出强度 vs 信用扩张 | 贷款增速能否回到名义 GDP 之上、准财政是否继续补丁化 |
| 15 | 外贸-进口轴 | 进口结构与顺差 | 进口增速能否持续反超、卡点清单（存储/元件）是否缩短 |
| 16 | 通道重排轴 | 陆运/海运通道 | 订舱市场化、单证金融化、班列与北极航线货量 |
| 17 | 气候灾害轴 | 极端天气强度 | 雨带偏移、粮食与电力、救灾资金追加 |
| 18 | 历史叙事轴 | 纪念日程 | 纪念是否闭环、是否转入"空间化＋产业化"（公园、旅游、运营） |

### 怎么用轴

- 每条日报的条目，除了层级与判断词，**尽量挂一条轴**（挂不上说明它可能只是新闻）
- 轴不追求"每天有更新"；**轴的价值在跨月比较**：同一轴三个月前的阶段与今天的阶段，就是结论
- 阶段迁移要留痕：`轴 → 日期 → 阶段 → 触发文本 → 判据核对结果`

## 三、轴与链的接口

| 问题 | 用哪个 |
|---|---|
| 这条国际新闻会走到中国哪个环节？ | 链 |
| 这个议题三个月来在推进还是停滞？ | 轴 |
| 政策方向与市场定价不一致？ | 链（金融端）＋轴（政策端）对撞 |
| 判断该给"落子"还是"兑现"？ | 轴上的阶段，＋证据等级（表态/名词层/硬交付） |

## 四、与下游的接口

日报除了给判断，还要输出**可被下游复用的因果链**（1–3 条/日）：

```yaml
跨库因果链:
  - 上游: "事件摘要，含关键数字"
    下游: "策略:…；技术:…；三观:…"
    类型: 定调 / 升级 / 定价 / 兑现 / 验证
    推演逻辑: "机制说明；判据＝可核查的后续动作/价位/日期"
```

三条铁律：

1. **编号唯一**：同一事件只用一个编号，发现重号当日登记并废止其一
2. **判据必写**：没有判据的链不是链，是评论
3. **窗口**：常规 30 天核销，重大轴回溯 90 天

## 五、轴的淘汰

轴会死。出现下列任一情况，轴进入观察区并在 30 天内决定去留：

- 连续 60 天无新节点
- 驱动变量已被其他轴吸收（如某轴只是另一轴的分支）
- 判据全部兑现或全部证伪（意味着结论已完成，不需要再跟）

**轴的数量不追求增长**。18 条能覆盖当前主要线索，就停在 18 条。

# 信号检测 · 六类分法 + 45 组措辞差分

> 措辞差分是本方法的核心武器：它给出的是**因果型信号**，而不是相关性猜测。
> 所有例句都来自已公开播出的文本，日期仅用于可追溯。

## 一、六类信号怎么找

| 类 | 找什么 | 命中标志 |
|---|---|---|
| ① 文本用词对照 | 同一议题前后表述差异 | "以往…这次""以前…现在""不再提" |
| ② 数据口径与报道选择 | 只报环比/同比、只报分项、何时报 | 该报不报、只报一半、数据披露时点反常 |
| ③ 排序·规格·时机 | 并列项先后、出席规格、文体规格 | 排序被调整、唁电国对国 vs 国对私 |
| ④ 提及与未提及 | 对 A 讲、对 B 不讲；不接话茬 | 对照组存在时最有效 |
| ⑤ 军事安全表述 | 如期→冲刺、静默天数、点名变化 | 时间词替换形容词、连续静默 |
| ⑥ 定性新提法 | 首次出现的定性、定性平台升格 | "首次""新型""首次在多边场合" |

**检测提示词**（读稿时脑中过一遍）：注意 / 有意思 / 罕见 / 反常 / 以往…这次 / 以前…现在 / 没提 / 未提 / 首次 / 特意 / 排在第几。

## 二、45 组实测差分

### 2.1 常设机制（32 组）

| # | 措辞变化 | 含义 |
|---|---|---|
| 1 | 加力扩围 → 优化 / 用好 | 政策**降级**（子弹用尽或效果有限） |
| 2 | 协同 → 引领 | 政策**升级**（地位提升） |
| 3 | 用力防风险 → 防风险 → 从清单消失 | 风险**缓解**进程 |
| 4 | 新提法首次出现 / 消失的表述 | 新方向**确立** / 旧方向**退潮** |
| 5 | 足以摧毁 → 足以封锁 / 无限期维持 | **实力受限的降级表述＝预期管理、军事选项被排除** |
| 6 | 弹药充足 → 其他类型"略微紧张" | **否认中的承认＝实际短缺严重** |
| 7 | 数据披露时点选择 | **为何现在报这个数字＝政策信号** |
| 8 | 尽快重创 → 逐步扼杀 | **打击选项被排除的官方自白** |
| 9 | 任务完成 / 单方宣布胜利 | **叙事战自我定调** |
| 10 | 防御转进攻（角色错位） | **造势而非意图**（用错部门表态） |
| 11 | 公开时间表 | 预期管理公开化、给自己留退路 |
| 12 | "暂不打击至某节点后" → "战事将在该节点后立即结束" | **时间表从"不打"改口"结束"＝从拖延转向收尾** |
| 13 | 稳定市场 → 研究出台… → 24 小时落地 | **动词层级递进＝工具句取代目标句** |
| 14 | 编制规划 → 编制**实施** | 从发文期进入执行期 |
| 15 | 原则性反对 → "坚持反对…的正确立场…奠定坚实基础" | 从宣示到条件（给对方设可记账科目） |
| 16 | "建设性战略稳定关系" → "基于尊重、公平、对等" | 半年内二次扩容＝**语言层先付款** |
| 17 | 补短板 → 长板技术 | 追赶者语言 → 领先者语言 |
| 18 | "完全且决定性控制" → "重开的…条件" | 封锁改写成**可交易标的** |
| 19 | 沉默 → "采取一切必要措施" | 沉默被打破＝组织化反击启动 |
| 20 | 倡导式账期 → "60 日付现＋6 个月上限＋联合约谈" | 出现**可罚条款**＝政策从倡导转执行 |
| 21 | 条件式红线 → 无条件式红线 | 删掉弹性表述＝红线明确化 |
| 22 | 国际油价从数据变标题 | **输入性通胀预期公开提示** |
| 23 | 打击目标"选择式" → "豁免名单式" | 从"打什么"改为"什么不打"＝**规则文本化** |
| 24 | 介入门槛：战略价值 → 本国伤亡 | **伤亡是出兵权的标价器** |
| 25 | 制裁工具"批次排期式" → "部分解除禁令＋吨数" | 数字句 → 机制句＝**从指标变成规则开口** |
| 26 | 角色"代理人后台" → "调解担保方" | 把不可交易的立场换成**可交付的服务** |
| 27 | 讲话"单一理念层" → "道/术两层" | 承认"过去重道轻术"＝进入项目交付期 |
| 28 | 安全供给"国家间求援" → "共同防御条款" | 条款被援引，但**无兵力/无指挥/无时限＝成本为零的背书** |
| 29 | 战争目标清单＋"数据处理中心" | **算力与数据基础设施进入交战清单＝机房等价弹药库** |
| 30 | "停火是选举前提" → "考虑战时选举换停火 60 天" | **合法性成为货币、停火成为价格** |
| 31 | 财政工具"进度陈述" → "1.3 万亿发行完毕" | **额度耗尽型收尾**（与效果不佳型降级必须分开读） |
| 32 | 全年目标"承诺式" → "4.6% 符合全年预期目标" | **目标重定义**（承诺→认证，提前卸压） |

### 2.2 后期新增（13 组）

| # | 措辞变化 | 含义 |
|---|---|---|
| 33 | 生育政策"优化/促进长期均衡发展" → "**努力稳定新出生人口规模**"；"人口红利" → "**人口综合红利**"；"均等化覆盖" → "资源与人口变化**动态适配**" | 从"调结构"退到"保总量"、从"覆盖"退到"适配"＝**收缩型公共资源配置**；判据是"有没有新钱"而非"有没有新词" |

| 36 | 健康方针"把健康融入所有政策" → "规划、政策、项目、工程**等优先考虑**健康影响" | **从理念融入变为节点审查＝原则无法追责、节点可以被卡住** |
| 37 | 并列项"优质高效"在前 → "**均衡普惠、优质高效**"＋预防/基层在前 | **排序即资源配置的负面清单**：前沿部分靠企业自担，财政只保普惠 |
| 38 | 算力"工程/集群"（产业项目）→ "**国家规划建设的'六张网'之一**"＋算电/算水协同 | **由产业项目升格为国家基础设施＝定价方式从审批转向网络化费率与目录管理** |
| 39 | 价格治理"反垄断高价/明码标价"（治贵）→ "**不正当价格行为认定标准**""治理**低价无序竞争**" | **治理方向反转：从治高价扩展到治倾销低价＝反内卷从自律升为法律责任** |
| 40 | 巡视对象"中央和国家机关" → "**教育部＋31 所中管高校**" | **从"查部委"转向"查人才供给"＝对规划交付能力的检查** |
| 41 | "**如期**实现" → "**冲刺**实现" | 从目标宣示转为进度确认；**时间词优先于形容词** |

| 43 | 唁电"只表达哀悼与评价" → 加"**希望当政者珍视…恪守…文件**" | **礼节文体首次承载对现政权的条件式要求＝借最软的文体递最硬的账单** |

| 45 | 岁末"**加大**逆周期调节/加力扩围/努力完成" → "**用好用足**""**深入挖掘**""**确保完成**" | **四个动词全为存量语言＝无新增量的官方确认** |

## 三、判读纪律（三条，比表格更重要）

### 1. 形似的降级，必须先分清三种成因

| 类型 | 表面相似 | 真实含义 |
|---|---|---|
| **效果不佳型降级** | 加力扩围 → 优化/用好 | 政策退坡，工具还在 |
| **额度耗尽型收尾** | 发行中 → 发行完毕 | 工具见底，不是不想用 |
| **目标重定义** | 承诺 → 认证 | 考核标准下移 |

三者对资产与产业的含义完全不同。**判错成因，比判错方向更致命。**

### 2. 差分要有对照组

- 跨期对照：同一议题前后两次表述
- 跨对象对照：对 A 讲了、对 B 没讲
- 跨案例对照：同类文体（唁电/贺信/致电）的规格矩阵

没有对照组的"变化"，只是自己的感觉。**只有单日文本时，不做跨期差分结论。**

### 3. 差分结论必须写在措辞上，不写在动机上

正确：「从'加力扩围'改为'用好用足'，四个动词全部是存量语言，意味着不再有新增量」——措辞是可核对的。

错误：「中央不想刺激经济了」——这是心理推断，无法证伪。

## 四、一条信号进账本的要求

一条新差分要进这张表，必须凑齐三样：

1. **前后两个原句**（可核对）
2. **中间发生了什么**（时间窗）
3. **一个能证伪的判据**（下次看到同类变化，先看什么）

凑不齐的不进表，留在观察清单里。

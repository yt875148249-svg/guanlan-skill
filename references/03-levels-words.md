# 层级 · 判断词 · 主题词表

## 一、层级标准（S0–S6）

| 层级 | 内容 | 常见阶段 |
|---|---|---|
| S0 | 顶层活动、顶层定调、全会级文本 | 定调期 / 结账期 |
| S1–S2 | 中央重要会议、文件定方向 | 定调期 → 落子期 |
| S3–S5 | 部门部署、产业落子、资源配置 | 落子期 → 攻坚期 |
| S6 | 成果验证、数据发布 | 验证期 |

**校准规则**（来自实跑）：

- 全会级文本（决定/公报）＝S0，且判断词常为**结账期**——它不产生新任务，只做存量清算与行为规范。
- 全会**前后**的政治局会议若"只审议某项专项报告、不议经济"＝经济议题被让位，**本身即 S0 级信号**（方法 1 元信号）。

## 二、13 个受控判断词

「判断」字段必须用下表词汇，**同一条目只能给一个**。

| 判断词 | 适用场景 | 典型示例 |
|---|---|---|
| 定调期 | S0–S2 方向确立、资源未到位 | 政治局会议、总书记署名文章、全会决定稿 |
| 落子期 | S2–S5 任务分解、部门开始动作 | 国常会、部委规划印发、协调机制建立 |
| 攻坚期 | S4–S5 项目落地、执行推进 | 重大工程通航、贴息落地执行、政策性工具开工 |
| 验证期 | S6 数据反馈 | 出口、PMI、CPI/PPI、利润、贷款增速 |
| 升级期 | 外部冲突/风险烈度上升 | 打击范围扩大、重大灾害 |
| 延续期 | 事件持续演进、未见转折 | 抗议扩散、修宪争议 |
| 博弈期 | 多方反复、信号混乱、谈判与威慑并行 | 制裁与复谈同时进行、通道规则战 |
| 转折期 | 趋势方向改变（政策/事件反转） | 点位停火、谈判与停火切割 |
| 兑现期 | 重大外交/制度交付落地、清单上的事按期交付 | 国事访问、工程通航、工具投放完成 |
| 收尾期 | 冲突/议题进入日程化退出，从"如何赢"转入"如何体面地不赢" | 设定期限、写信要时间表、委托第三方 |
| 结账期 | 存量清零、口径公开化、处分端消化存量 | 处分数量大于立案、财政四条腿用尽 |
| 定型期 | 制度/市场从"探索"进入"定型"，出现可复制样板 | 首个区域性市场正式运行、组织入法人要件 |
| 拖延期 | 不解决只排期，用日历代替方案 | 谈判排到某日期之后、"以拖待变" |

**规则**：

- S0–S5 国内条目：定调 / 落子 / 攻坚 / 兑现 / 结账 / 定型
- S6 国内数据条目：验证期
- S6 国际冲突/灾害/金融类：升级 / 延续 / 博弈 / 转折 / 收尾 / 拖延
- 数据类国际条目：验证期

**博弈期内部细化（攻守易势）**：持续监测**谁在极限施压、谁在做预期管理**——攻守互换是转折前奏。观察点：谁先释放让步、让步幅度是否超过其筹码价值（方法 56）。

### 新主题登记流程

1. 在主题索引目录建索引页（复用同一模板）
2. 日报的条目主题用新词，并链接索引页
3. 在词表里追加，保证回补任务用词一致
4. **新词的必要性要写明**：为什么现有 52 个词覆盖不了它

## 四、条目数据结构

每条必须齐六个字段：

| 字段 | 约束 |
|---|---|
| 序号 | 与正文条数一致 |
| 主题 | 词表固定词 |
| 层级 | S0–S6 |
| 事件 | 一句话，≤60 字，只写事实 |
| 判断 | 13 个受控词之一 |
| 关键词 | 3–5 个具体名词（不写形容词） |

可选字段：`关键表述`（原文核心句）、`前瞻期限`（关联倒计时节点）、`证据等级`（表态 / 名词层 / 硬交付）、`口径`（盘中/收盘/跨源）。

### YAML frontmatter 模板

```yaml
---
类型: 解读
来源: YYYY.MM.DD 新闻联播（文字稿）
日期: YYYY-MM-DD
关键词: [3-5个具体名词]
核心内容: N条解读——①… ②… ③…（一句话概括每条核心判断）
条目:
  - 序号: 1
    主题: 党建
    层级: S0
    事件: 一句话（≤60字）
    判断: 定调期
    关键词: [..]
跨库因果链:
  - 上游: "事件摘要（含关键数字）"
    下游: "策略:…；技术:…；三观:…"
    类型: 定调 / 升级 / 定价 / 兑现 / 验证
    推演逻辑: "机制说明；判据＝可核查的后续动作/价位/日期"
---
```

**铁律**：frontmatter 内的引号一律用中文引号，英文引号会触发解析失败（已发生过一次全批断档）。
